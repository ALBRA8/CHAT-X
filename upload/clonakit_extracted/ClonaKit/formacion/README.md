# Formación de ClonaKit

Estas lecciones son la guía por escrito del tutor de ClonaKit. Puedes seguirlas solas o junto a los comandos `/empezar`, `/clonar` y `/desplegar` dentro de Claude Code. Si es tu primera vez, hazlas en orden.

## Empieza por las diapositivas

[**Formación exprés: clonar apps de forma legal**](diapositivas.html): 11 diapositivas, unos 5 minutos, sobre uso personal y comercial. Ábrelas con doble clic o con `npm run diapositivas`.

## Lecciones

0. [Bienvenida a ClonaKit](00-bienvenida.md): qué es el kit, qué significa "clonar" de forma legal, las 5 fases y qué necesitas.
1. [Prepara tu ordenador](01-preparar-tu-ordenador.md): la terminal, Node.js, Git, Claude Code y la descarga del kit, hasta escribir `/empezar`.
2. [Lo legal: clonar sin copiar](02-lo-legal.md): qué puedes recrear y qué no, el método sala limpia y el checklist de `LEGAL.md`. La más importante.
3. [Investiga una app](03-investigar-una-app.md): cómo encontrar la ruta de una app o usar una web, lanzar la investigación y leer el informe.
4. [De la ficha al código](04-de-la-ficha-al-codigo.md): elegir un MVP, escribir tu `FICHA.md` con tus palabras y pedir cambios a Claude.
5. [Prueba tu app en local](05-probar-en-local.md): `localhost`, `npm run probar`, la consola del navegador y los permisos de cámara y pantalla.
6. [Git y GitHub](06-git-y-github.md): guardar versiones de tu app y subirla a GitHub sin filtrar contraseñas.
7. [Publica tu app en Vercel](07-desplegar-en-vercel.md): desplegar tu repositorio, conseguir tu dirección `.vercel.app` y publicar con cada `push`.
8. [Dominio propio y actualizaciones](08-dominio-y-actualizaciones.md): conectar un dominio, actualizar y volver atrás, escribir un buen README y compartir con responsabilidad.

**Glosario:** [todas las palabras técnicas explicadas](glosario.md).
